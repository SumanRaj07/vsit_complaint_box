# VSIT Complaint Box

A Flutter application for submitting and tracking complaints, featuring a dedicated admin dashboard for complaint management.

## Features

*   **Submit Complaints:** Users can easily submit complaints or issues they are facing.
*   **Track Complaints:** Users can track the status of their submitted complaints.
*   **Admin Dashboard:** A secure login for administrators to view, manage, and resolve user complaints.
*   **Modern UI:** A clean, glassmorphism-inspired UI with smooth animations.

## Project Structure

*   `lib/models/` - Data models (e.g., Complaint)
*   `lib/providers/` - State management using Providers
*   `lib/screens/` - UI screens for the app (Submit, Track, Admin Login, Admin Dashboard)
*   `lib/theme/` - Application theme and styling
*   `lib/widgets/` - Reusable UI components (Glass cards, Priority badges, etc.)

## Getting Started

To build and run this project, you will need Flutter installed on your machine.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/SumanRaj07/vsit_complaint_box.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd vsit_complaint_box
    ```
3.  **Install dependencies:**
    ```bash
    flutter pub get
    ```
4.  **Run the app:**
    ```bash
    flutter run
    ```
